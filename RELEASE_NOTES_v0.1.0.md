# v0.1.0 — Initial documentation release (draft)

First publication of an experimental reconstruction of the directional Potensic ATOM remote-controller-to-Android USB-C adapter cable.

## Included

- Editable KiCad schematic and A3 schematic PDF, revision 0.4.10.
- Multimeter-derived wiring/resistance reference values.
- 3D-printable holder with strain relief (STL).
- Parts list, controller-side SBU extension requirements, build notes.
- Observations from a working Android/DSRC02A prototype and short flight test.
- Explicit list of unverified compatibility claims and safety limitations.
- Dual licensing: CERN-OHL-S-2.0 (hardware and 3D files) and CC BY 4.0 (documentation).

## Known limitations

- Designed around a particular Potensic ATOM / DSRC02A / Android setup.
- No oscilloscope/protocol/compliance testing; no long-term durability qualification.
- Alternative extension and other drone models untested.
- Attribution details / GitHub URL and final owner review required **before publishing**.
