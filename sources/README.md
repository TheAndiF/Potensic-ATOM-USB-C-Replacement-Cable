# Reference documents

Original reference manuals were supplied by the project owner:

- `Potensic_ATOM_User_Manual_DE_202507.pdf`
- `Potensic_ATOM_User_Manual_EN_202511.pdf`

They are **not bundled** in this initial public release draft pending an explicit redistribution-rights decision. Use manufacturer's current publications or the owner's legally acquired copies to check operating instructions and controller identity.

Additional public references:

- Official Potensic accessory listing: https://store.potensic.com/products/usb-cable-for-atom-series-drone
- Official USB-IF USB Type-C specification and cable guidance: https://www.usb.org/documents
- Android Open Accessory documentation: https://source.android.com/docs/core/interaction/accessories/aoa

The supplied KiCad PDF and source-file snapshots are included because they are the project's own design artifacts. The exact controller-side USB-C extender is a mechanically required component of the **reported prototype**, not a certified universal solution.
